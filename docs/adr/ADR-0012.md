# ADR-0012: Adopt "VEEE" as the name for the UX language layer

- **Status**: Accepted
- **Date**: 2026-08-01
- **Decision Maker**: VUMA project lead
- **Supersedes**: The name "VELL" used in `vuma-swe-package/22-review-against-vuma.md`,
  `23-vell-redesign-research.md`, `26-new-plans-three-layers.md`
- **Superseded by**: (none)

## Context

The SWE package (`vuma-swe-package/`) introduced a higher-level UX
language layer called "Vell" — a language that compiles to VUMA AST,
built on incremental computation (Salsa), monotonicity types
(Datafun), algorithm/schedule separation (Halide), and e-graph
optimization. The name "Vell" was chosen without much deliberation
and has several problems:

1. **Phonetic ambiguity**: "Vell" sounds like "vial," "veil," or the
   German "wohl" — none of which evoke the VUMA lineage.
2. **Branding collision**: "Vell" collides with "Vellum" (a publishing
   tool), "Vela" (a satellite constellation), and "Vel" (a common
   given name). Search discoverability is poor.
3. **No explicit VE³ reference**: The user's intent is that the name
   should evoke "VE cubed" — three E's that capture the language's
   essence. "Vell" has only one E and doesn't signal this.
4. **Inconsistent capitalization in the SWE package**: "Vell,"
   "VELL," "Vela" all appear in different files.

The user has requested renaming VELL to VEEE (pronounced "VE cubed" —
V·E·E·E).

## Decision

**Adopt "VEEE" as the official name for the UX language layer.**

### Etymology

**VEEE = V·E·E·E = "Verified Expression Evaluation Engine"**

- **V** = VUMA (the systems language VEEE compiles to)
- **E₁** = **Verified** — VEEE programs inherit VUMA's PMT verification
  (Z3 contract discharge, Lean formal spec). This is the durable moat
  vs. React/SwiftUI/Compose — no other UX language compiles to a
  verified systems language.
- **E₂** = **Expression** — VEEE is expression-oriented (everything
  evaluates to a value; no statements). This aligns with the
  incremental-computation model (Salsa/Adapton) where signals are
  first-class expressions.
- **E₃** = **Evaluation** — VEEE's defining feature is demand-driven
  evaluation (seminaïve delta evaluation per Datafun). The "Evaluation"
  word anchors the brand on this distinguishing mechanism.

### Alternatives considered (etymology)

- **Option B: "Visual Embedded Ergonomic Engine"** — rejected.
  "Visual" and "Embedded" are generic; "Ergonomic" is a soft benefit,
  not a defining feature. Doesn't reference verification.
- **Option C: "VUMA's Expressive End-User Engine"** — rejected.
  "End-User" is misleading (VEEE is for UI developers, not end users).
  "Expressive" is vague.

### Pronunciation and branding

- **Pronounced**: "vee-eee" (three syllables) or "vee-cubed" (casual)
- **Logo concept**: `V³` (V with superscript 3) or `Vᴱᴱᴱ`
- **File extension**: `.veee`
- **Repository**: `veee` (sibling to `vuma`)
- **Compiler binary**: `veeec` (analogous to `rustc`)
- **Language server**: `veee-lsp`

## Consequences

### Positive
- **Explicit VE³ reference** — the name signals "three E's that mean
  something," matching the user's intent.
- **Search discoverability** — "VEEE" is distinctive; no clashes with
  existing project names found.
- **Brand consistency** — VEEE clearly derives from VUMA (the V),
  signaling the compilation target relationship.
- **Pronounceable** — "vee-eee" is easy to say in conversation and
  presentations.

### Negative
- **SWE package files are now stale** — `22-review-against-vuma.md`,
  `23-vell-redesign-research.md`, `26-new-plans-three-layers.md` all
  use "Vell"/"VELL." These are historical artifacts and won't be
  rewritten (the rename is forward-looking).
- **Four-character all-caps name** — "VEEE" in all caps is visually
  unusual. Convention will be: "VEEE" (all caps) when referring to the
  language/project, "veee" (lowercase) for filenames/commands.

### Neutral
- The name "Vell" is preserved in the SWE package as a historical
  artifact. Engineers reading the SWE package should be told "Vell =
  VEEE (renamed)" via this ADR.

## Alternatives Considered

### Alternative A: Keep "Vell"
Rejected — phonetic ambiguity, branding collision, no VE³ reference.

### Alternative B: "Vela"
Rejected — collides with the satellite constellation. Same phonetic
problems as "Vell."

### Alternative C: "VumUI" or "Vumal"
Rejected — doesn't capture the "higher-level language" nature. Sounds
like a VUMA library, not a separate language.

### Alternative D: "Cube" or "V³" (no expansion)
Rejected — too cryptic. Needs the four-letter expansion for
documentation and search.
